# Портфельный калькулятор: Россия (реальные доходности)

Учебный веб-калькулятор по бизнес-аналитике. Собирает портфель из 10 российских индикаторов
по теории Марковица. Все доходности пересчитаны в **реальные**, то есть очищены от инфляции.

## Индикаторы (помесячно, 12.2012 – 08.2026)
| № | Индикатор | Источник |
|---|---|---|
| 1 | Денежная масса М2 | Банк России |
| 2 | Акции крупных компаний — индекс MCFTR (с дивидендами) | Московская биржа |
| 3 | Акции малых и средних компаний — MESMTR (с дивидендами) | Московская биржа |
| 4 | Гособлигации ОФЗ — RGBITR | Московская биржа |
| 5 | Корпоративные облигации — RUCBITR → RUCBTRNS | Московская биржа |
| 6 | Золото, руб./г | Банк России |
| 7 | Юань CNY/RUB | Банк России |
| 8 | Доллар USD/RUB | Банк России |
| 9 | Недвижимость Москвы — MREDC (ДомКлик) | Московская биржа |
| 10 | Денежный рынок / депозит (по ключевой ставке) | Банк России |
| доп. | Серебро, руб./г | Банк России |

Инфляция берётся из ИПЦ Банка России (прирост цен м/м с устранённой сезонностью). Как альтернативный
дефлятор можно выбрать рост денежной массы М2.

## Критерии оптимизации
1. Минимальная волатильность (портфель Марковица).
2. Максимальный коэффициент Шарпа (безрисковая ставка задаётся пользователем).
3. «Эффективный риск»: минимальный риск при заданной доходности.
4. «Эффективная доходность»: максимальная доходность при заданном риске.

## Что показывает калькулятор
- эффективную границу;
- кривую доходности и график просадок;
- интерактивную круговую диаграмму весов;
- ожидаемую доходность, волатильность, коэффициент Шарпа, CAGR, максимальную просадку
  и максимальный период восстановления;
- сравнение нескольких портфелей на одном графике;
- статистику и корреляции индикаторов.

## Структура проекта
```
app.py            — веб-сервер Flask (страница + API)
portfolio.py      — математика: реальные доходности, оптимизация, метрики
build_dataset.py  — сборка data/data.csv из сырых файлов data/raw/*.csv
data/             — данные
templates/, static/ — интерфейс (HTML, CSS, JavaScript + Plotly)
render.yaml       — настройки бесплатного хостинга Render
```

## Запуск на своём компьютере
```
pip install -r requirements.txt
python app.py
```
Потом откройте в браузере http://127.0.0.1:5000

## Размещение на Render
New → Web Service → подключить репозиторий. Build Command: `pip install -r requirements.txt`,
Start Command: `gunicorn app:app`, тариф Free.

# Калькулятор инвестиционного портфеля (Россия)

Учебная работа по бизнес-аналитике. Портфель из 10 российских индикаторов по теории Марковица.
Все доходности реальные: очищены от инфляции.

## Индикаторы (помесячно)
1. Денежная масса М2 — Банк России
2. Акции крупных компаний, индекс MCFTR (с дивидендами) — Московская биржа
3. Акции малых и средних компаний, индекс MESMTR (с дивидендами, с 12.2013) — Московская биржа
4. Гособлигации ОФЗ, индекс RGBITR — Московская биржа
5. Корпоративные облигации, индекс RUCBITR / RUCBTRNS — Московская биржа
6. Золото — Банк России
7. Серебро — Банк России
8. Юань — Банк России
9. Доллар США — Банк России
10. Недвижимость Москвы, индекс MREDC (с 12.2016) — Московская биржа / ДомКлик

Инфляция — индекс потребительских цен Росстата без сезонного сглаживания (файл `ipc_mes_*.xlsx`).

Индексы биржи скачаны с её сайта (файлы `MCFTR.csv`, `MESMTR.csv`, `RGBITR.csv`, `RUCBITR.csv`, `RUCBTRNS.csv`, `MREDC.csv` в `data/raw`).
Общий период всех индикаторов: январь 2017 — август 2026 (116 месяцев); позже всех начинается индекс недвижимости.

## Критерии оптимизации
1. Минимальная волатильность.
2. Максимальный коэффициент Шарпа (безрисковая ставка задаётся).
3. Эффективный риск: минимальный риск при заданной доходности.
4. Эффективная доходность: максимальная доходность при заданном риске.

## Свой файл
В шаге «Данные» можно выбрать «Свой файл» и загрузить Excel (.xlsx, .xls) или CSV — один или несколько.
Устройство файла сайт определяет сам: разделитель, кодировку, десятичный знак, где даты, широкая таблица или длинная,
цены или доходности, дневные данные или месячные. Что и как прочитано, показано в отчёте под рамкой загрузки;
вид каждого столбца и способ учёта инфляции можно поменять. Пример подходящего файла скачивается там же.

## Дополнительные допущения (по умолчанию выключены)
- Доход помимо цены: аренда для недвижимости, проценты по вкладу для доллара и юаня.
- Издержки: комиссия с оборота при ежемесячном возврате долей и налог на доход в конце периода.

Ещё на странице:
- «Ход расчёта»: шесть этапов, по каждому видно, что вошло, что вышло и что отброшено;
- сноски «как посчитано» под каждым показателем — формула с подставленными числами;
- вкладка «Откуда результат»: вклад каждого индикатора в доходность и риск, путь рубля, таблица корреляций;
- риск потерь и коэффициент Сортино, таблица долей, выгрузка результата в Excel;
- проверка устойчивости долей к сдвигу периода;
- проверка на «будущем»: доли подбираются по ранней части периода, результат считается на поздней;
- рост денежной массы М2 как ориентир на графике кривой доходности;
- живая карточка в шапке: во что превратился 1 ₽, маленькая кривая и состав портфеля;
- карточка «что изменилось» после каждого пересчёта (было → стало) с кнопкой «вернуть как было»;
- подсказки к терминам: наведите на слово с пунктирным подчёркиванием;
- кнопка «сравнить все четыре критерия» на вкладке «Динамика и сравнение».

## Файлы
- `app.py` — веб-сервер (Flask)
- `portfolio.py` — расчёты
- `reader.py` — чтение загруженного файла Excel или CSV любого устройства
- `build_dataset.py` — сборка `data/data.csv` из файлов `data/raw`
- `templates/index.html`, `static/app.js`, `static/style.css` — страница
- `run.bat` — запуск на своём компьютере одним щелчком
- `tests/test_portfolio.py`, `run_tests.bat` — автоматические проверки расчётов

## Запуск на своём компьютере (Windows)
1. Установить Python 3.11 или новее с https://www.python.org/downloads/ (галочка «Add python.exe to PATH»).
2. Дважды щёлкнуть по `run.bat`. При первом запуске он сам установит библиотеки.
3. Сайт откроется по адресу http://127.0.0.1:5000

Вручную то же самое:
```
pip install -r requirements-local.txt
python app.py
```

## Проверка расчётов
Дважды щёлкнуть по `run_tests.bat` или выполнить `python -m unittest -v`. Должно быть `OK` (42 проверки).

## Запуск на Render
Build Command `pip install -r requirements.txt`, Start Command `gunicorn app:app`.

# Калькулятор инвестиционного портфеля (Россия)

Учебная работа по бизнес-аналитике. Портфель из 10 российских индикаторов по теории Марковица.
Все доходности реальные: очищены от инфляции.

## Индикаторы (помесячно)
1. Денежная масса М2 — Банк России
2. Акции крупных компаний, индекс MCFTR (с дивидендами) — Московская биржа
3. Акции малых и средних компаний, индекс MESMTR (с дивидендами, с 2019 г.) — Московская биржа
4. Гособлигации ОФЗ, индекс RGBITR — Московская биржа
5. Корпоративные облигации, индекс RUCBITR / RUCBTRNS — Московская биржа
6. Золото — Банк России
7. Серебро — Банк России
8. Юань — Банк России
9. Доллар США — Банк России
10. Недвижимость Москвы, индекс MREDC (с 12.2016) — Московская биржа / ДомКлик

Инфляция — индекс потребительских цен, Банк России.

## Критерии оптимизации
1. Минимальная волатильность.
2. Максимальный коэффициент Шарпа (безрисковая ставка задаётся).
3. Эффективный риск: минимальный риск при заданной доходности.
4. Эффективная доходность: максимальная доходность при заданном риске.

## Файлы
- `app.py` — веб-сервер (Flask)
- `portfolio.py` — расчёты
- `build_dataset.py` — сборка `data/data.csv` из файлов `data/raw`
- `templates/index.html`, `static/app.js`, `static/style.css` — страница

## Запуск
```
pip install -r requirements.txt
python app.py
```
На Render: Build Command `pip install -r requirements.txt`, Start Command `gunicorn app:app`.
